# Test Case 01: Independent Evaluation & Scoring

## Evaluation Overview

This document presents an independent evaluation of AI-generated responses to the same machine learning question.

Each response was assessed using the evaluation framework defined in:

`evaluation-framework.md`

The evaluation criteria were:

- Accuracy
- Relevance
- Completeness
- Clarity
- Logical Reasoning
- Instruction Following

Each criterion was scored on a scale from 1 to 5.

---

# Model 1: ChatGPT

## Evaluation

### Accuracy — 5/5

The response accurately explains that supervised learning uses labeled data to learn relationships and predict outcomes, while unsupervised learning works with unlabeled data to identify patterns or groups. The examples of spam detection and customer segmentation are appropriate and technically correct.

### Relevance — 5/5

The response directly addresses the requested comparison without introducing unrelated information. Every section contributes to explaining the difference between supervised and unsupervised learning.

### Completeness — 5/5

The response satisfies all major components of the prompt by defining both learning approaches, providing one practical example for each, and summarizing their key difference.

### Clarity — 5/5

The explanation uses simple language, clear separation between the two concepts, and an easy-to-understand summary. The structure makes it suitable for a beginner.

### Logical Reasoning — 5/5

The explanation follows a logical sequence: definition of supervised learning, example, definition of unsupervised learning, example, and a concise comparison. The conclusions are consistent with the explanations provided.

### Instruction Following — 5/5

The response follows all explicit instructions. It defines both concepts, provides practical examples, remains understandable to beginners, and stays below the 200-word limit.
