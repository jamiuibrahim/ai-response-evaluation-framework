# Test Case 01: AI Response Evaluation

## Task Category

Factual Research and Instruction Following

---

## Objective

Evaluate how different AI models respond to the same factual research question while following specific instructions.

---

## Test Prompt

> Explain the difference between supervised learning and unsupervised learning.
>
> Your response must:
>
> 1. Clearly define both concepts.
> 2. Provide one practical example of each.
> 3. Keep the explanation under 200 words.
> 4. Use language understandable to a beginner.

---

## Models to Evaluate

- ChatGPT
- Google Gemini
- Claude
- DeepSeek

---

## Evaluation Criteria

Responses will be evaluated using the following criteria:

- Accuracy
- Relevance
- Completeness
- Clarity
- Logical Reasoning
- Instruction Following

---

## Evaluation Method

Each response will receive a score from 1–5 for each evaluation criterion.

The evaluation will include both numerical scores and written justification to ensure decisions are transparent and evidence-based.
