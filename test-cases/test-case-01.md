# Test Case 01: Supervised vs Unsupervised Learning

## Task Category

Factual Explanation and Instruction Following

---

## Objective

Evaluate how different AI models explain a fundamental machine learning concept while following specific instructions regarding clarity, examples, and response length.

---

## Test Prompt

Explain the difference between supervised learning and unsupervised learning.

Your response must:

1. Clearly define both concepts.
2. Provide one practical example of each.
3. Keep the explanation under 200 words.
4. Use language understandable to a beginner.

---

## Models to Evaluate

The following AI models will be evaluated using the same prompt:

- ChatGPT
- Google Gemini
- Claude
- DeepSeek

---

## Evaluation Criteria

Each response will be evaluated using the following criteria:

- Accuracy
- Relevance
- Completeness
- Clarity
- Logical Reasoning
- Instruction Following

Each criterion will be scored using the evaluation framework defined in `evaluation-framework.md`.

---

## Evaluation Method

1. Submit the same prompt to each AI model.
2. Collect the responses without modifying their content.
3. Evaluate each response independently.
4. Assign a score from 1–5 for each evaluation criterion.
5. Document justification for every score.
6. Compare the responses.
7. Identify the strengths and weaknesses of each response.
8. Produce a final ranking based on the evaluation results.
